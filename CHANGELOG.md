## 0.1.0

- First release, with two gothic dark themes for VS Code and Cursor that share one syntax palette:
  - **Villa Diodati**: veil teal, acid gold and wine-rose on a mossy green-black background.
  - **Villa Diodati Crypt Black**: the same colors on a near-black background with a faint moss tint.
- Palette inspired by stills from Guillermo del Toro's *Frankenstein*, named after the Lake Geneva villa where Mary Shelley conceived the novel.
- Covers the current workbench and Cursor UI (chat and inline edits, command center, sticky scroll, bracket pairs, inlay hints, diffs and merge editor) and turns on semantic highlighting.
- Language support includes JSX/TSX components, Vue templates and Rust (macros, attributes, lifetimes, format placeholders).
- Syntax colors meet 4.5:1 and comments 3:1 on both editor backgrounds.
- Terminal: the character under the block cursor stays visible, and the bright blue matches the buttons so labels keep white text.
- A lifted veil teal is used only for the cursor, matching brackets and find matches.
